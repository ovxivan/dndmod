# dndmod

Режим «Не беспокоить» для GNOME на Ubuntu 24.04 в стиле `cmatrix`.

По команде или сочетанию клавиш экран закрывается падающими символами поверх
обоев, уведомления отключаются, системные сочетания клавиш (Alt+Tab, Super,
Alt+F4, жесты) не работают. Выйти можно только вслепую набрав пароль
текущего пользователя — без Enter, режим снимается сразу, как только пароль совпал.

## Требования

- Ubuntu 24.04, GNOME Shell 46, сеанс Wayland
- `gjs`, `gdbus`, `file` (есть в системе по умолчанию)
- шрифт `Noto Sans Mono CJK JP` (пакет `fonts-noto-cjk`, ставится с Ubuntu)

## Установка

```bash
./install.sh                    # сочетание клавиш по умолчанию Super+Shift+M
./install.sh '<Control><Alt>d'  # своё сочетание
```

Скрипт ставит:

| Что | Куда |
|---|---|
| команда `dndmod` | `~/.local/bin/dndmod` |
| расширение GNOME Shell | `~/.local/share/gnome-shell/extensions/dndmod@ovxivan/` |
| man-страница | `~/.local/share/man/man1/dndmod.1` |
| сочетание клавиш | Настройки → Клавиатура → Свои сочетания → `dndmod` |

После **первой** установки выйдите из сессии и зайдите снова — на Wayland
GNOME Shell загружает новые расширения только при входе. Дальнейшие
обновления (`./install.sh`) подхватываются при следующем запуске `dndmod`
без перезахода, кроме правок `extension.js`.

Проверка:

```bash
gnome-extensions info dndmod@ovxivan   # Состояние: ACTIVE
man dndmod
```

## Использование

```bash
dndmod                          # включить режим
dndmod --code                   # режим с набором кода из активной сессии Claude Code
dndmod -w ~/Pictures/bg.jpg     # запомнить картинку фона и включить режим
dndmod --wallpaper-reset        # фоном снова будут обои рабочего стола
dndmod --palette                # показать палитру текущего фона
dndmod --palette ~/img.png      # показать палитру любой картинки
dndmod --stop                   # аварийно выключить режим
```

### Выход из режима

Наберите пароль своей учётной записи. На экране ничего не отображается.

| Клавиша | Действие |
|---|---|
| символы | добавляются к набранному, после каждого идёт проверка |
| Backspace | удалить последний символ |
| Escape | очистить набранное |
| пауза больше 2 с | следующее нажатие начинает набор заново |

Раскладку переключать не нужно: на время режима включается `us`, после
выхода возвращается прежняя.

### Аварийный выход

Если пароль не принимается:

1. `Ctrl+Alt+F3` — текстовая консоль, войдите своим логином и паролем.
2. `dndmod --stop`
3. Вернитесь в графическую сессию: `Ctrl+Alt+F2` (если не сработает — `Ctrl+Alt+F1`).

Эта подсказка выводится внизу экрана во время режима.

## Фон и палитра

- Фон — картинка из `dndmod -w FILE`, а если она не задана или файл
  пропал — текущие обои рабочего стола (с учётом тёмной темы). Слайдшоу
  (`.xml`) не поддерживается — тогда фон чёрный.
- Картинка заполняет каждый монитор с обрезкой краёв и затемняется на 55%.
- Цвета символов берутся из картинки: до четырёх преобладающих насыщенных
  оттенков, частота цвета соответствует его доле на картинке. Тёмные оттенки
  высветляются для читаемости. Если цветных оттенков нет — классический зелёный.

Посмотреть палитру заранее, не включая режим:

```bash
dndmod --palette ~/Pictures/bg.jpg
```

## Код из сессии Claude Code

`dndmod --code` поверх приглушённой матрицы открывает окно, в котором
посимвольно «набирается» код, написанный Claude в активной сессии Claude Code.

- Сессия — самая свежая из запущенных `claude` (`~/.claude/sessions/<pid>.json`,
  процесс жив). Код берётся из её истории `~/.claude/projects/<папка>/<sessionId>.jsonl`:
  вызовы `Write` (файл целиком), `Edit` и `MultiEdit` (новый фрагмент).
- Сначала набирается история сессии по порядку. Каждые 2 секунды проверяются
  новые записи: свежий код прерывает историю на конце строки и набирается сразу.
- Если нового кода нет 20 секунд после конца очереди, история начинается заново.
- Фрагмент длиннее 200 строк обрезается. Файлы `.env*`, `*.pem`, `*.key`,
  `id_rsa*`, `credentials*` не показываются; значения `api_key`, `secret`, `token`,
  `password` и похожих маскируются `••••••`.
- Нет активной сессии — показывается обычная матрица.

Сочетание клавиш запускает обычный режим без кода.
Форматы файлов Claude Code внутренние и не документированы: после обновления
Claude Code режим кода может перестать находить сессию.

## Как это устроено

Обычное окно на Wayland не может перехватить системные сочетания клавиш —
это делает только GNOME Shell. Поэтому режим реализован расширением,
которое захватывает ввод так же, как экран блокировки.

```
dndmod (bash) ──D-Bus──▶ extension.js (загрузчик) ──import──▶ mode.js ──▶ palette.js  фон и палитра
                         org.gnome.Shell                      оверлей,  └─▶ claude.js   код из сессии
                         /org/gnome/Shell/Extensions/Dndmod   пароль,       (только --code)
                         Start / StartWithOptions / Stop      раскладка
```

| Файл | Назначение |
|---|---|
| `dndmod` | CLI: включение, выключение, фон, палитра |
| `dndmod@ovxivan/extension.js` | загрузчик: D-Bus `Start`/`Stop`, горячая перезагрузка модулей |
| `dndmod@ovxivan/mode.js` | режим: оверлей, анимация, захват ввода, проверка пароля, уведомления, раскладка |
| `dndmod@ovxivan/palette.js` | выбор картинки фона и расчёт палитры |
| `dndmod@ovxivan/claude.js` | поиск активной сессии Claude Code и чтение кода из её истории |
| `dndmod@ovxivan/palette-cli.js` | вывод палитры в терминал для `--palette` |
| `dndmod.1` | man-страница |
| `install.sh` | установка |

Пароль проверяется системным помощником PAM `/usr/sbin/unix_chkpwd`.
GJS кеширует модули по пути, поэтому загрузчик при изменении любого модуля
(все `*.js`, кроме `extension.js`) копирует их в `$XDG_RUNTIME_DIR/dndmod/<метка>/`
и импортирует оттуда — так обновления и новые модули работают без перезахода в сессию.

## Файлы во время работы

| Файл | Содержимое |
|---|---|
| `~/.config/dndmod/wallpaper` | путь к картинке из `dndmod -w` |
| `~/.local/state/dndmod/show-banners` | исходное состояние уведомлений, пока режим включён; если сессия оборвалась, по нему уведомления восстанавливаются при следующем входе |
| `$XDG_RUNTIME_DIR/dndmod/` | копии модулей для горячей перезагрузки |

## Ограничения

- Переключение на текстовые консоли (`Ctrl+Alt+F1…F12`) не блокируется —
  как и на штатном экране блокировки; в консоли всё равно нужен пароль.
- `dndmod --stop` выключает режим без пароля. Сделать это может любая
  программа, запущенная от вашего пользователя, но не человек за клавиатурой.
- Каждое нажатие до совпадения пароля пишет в системный журнал
  `unix_chkpwd: password check failed`. Блокировки учётной записи это не вызывает.
- Изменение `extension.js` по-прежнему требует перезахода в сессию.
- Код на экране видит любой, кто подойдёт. Маскировка секретов — по шаблонам
  и ловит не всё.
- Для `--code` поддерживается одна сессия — самая свежая; код субагентов не показывается.

## Диагностика

```bash
journalctl --user -b | grep dndmod          # сообщения расширения
journalctl -t unix_chkpwd --since "-10min"  # проверки пароля
ls ~/.local/state/dndmod/                   # непусто — режим включён или оборвался
gsettings get org.gnome.desktop.notifications show-banners
```

Пароль не принимается — проверьте, что системная проверка его видит
(команда в bash, пароль не выводится):

```bash
bash -c 'read -rsp "Пароль: " p; echo; printf "%s\0" "$p" | /usr/sbin/unix_chkpwd "$USER" nonull; echo "rc=$?"'
```

`rc=0` — пароль верный, `rc=7` — нет.

## Удаление

```bash
dndmod --stop
gnome-extensions disable dndmod@ovxivan
rm -rf ~/.local/share/gnome-shell/extensions/dndmod@ovxivan \
       ~/.local/bin/dndmod ~/.local/share/man/man1/dndmod.1 \
       ~/.config/dndmod ~/.local/state/dndmod
```

Сочетание клавиш удаляется в Настройки → Клавиатура → Свои сочетания.
